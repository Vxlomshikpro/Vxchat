# VXChat

Клиентский Fabric-мод для приватного чата на Minecraft **1.21.11**.

Исходящие сообщения шифруются в иероглифы. Игрок с тем же модом, который успешно
прошёл синхронизацию, видит обычный текст. Остальные видят правдоподобный
китайский текст.

```
ты пишешь:        привет, как дела?
в чате у всех:    果河针风杉影之家瓜果雨瓜影手?之家猫秋之猫海花瓜金影
у игрока с модом: привет, как дела?
```

---

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer) для 1.21.11.
2. Положи в папку `mods`:
   - `fabric-api-0.141.6+1.21.11.jar`
   - `vxchat-<версия>.jar` (из `build/libs/`)
3. Mod Menu необязателен — с ним появится кнопка «Настроить».
4. Нужен Java 21.

Сборка из исходников:

```bash
./gradlew build
```

Готовый jar: `build/libs/vxchat-<версия>.jar`

## Команды

Все команды клиентские — на сервер они не отправляются и в его логах не появляются.

| Команда | Что делает |
|---|---|
| `/vxchat <игрок>` | начать синхронизацию (хендшейк) с игроком |
| `/vxchat gui` | открыть окно настроек |
| `/vxchat reset` | сбросить синхронизации на этом сервере |
| `/vxon` | включить шифрование |
| `/vxoff` | выключить шифрование |
| `/vxkey <ключ>` | задать ключ (пароль) для хендшейка |
| `/vxdm <команда>` | задать команду личных сообщений (`msg`, `dm`, `w`, `tell`, …) |
| `/vxreload` | перезагрузить конфиг с диска |

`/vxchat` без аргументов выводит этот список. По Tab подставляются `gui`, `reset`
и ники игроков онлайн.

## Как это работает

### Шифр

Статическая подстановка: один символ → один иероглиф.

- Перед шифрованием текст приводится к нижнему регистру.
- Знаки препинания и символы вне таблицы остаются как есть.
- Пробел кодируется иероглифом `之`, при расшифровке `之` даёт пробел.
- Пароль на шифр **не влияет** — таблица одинакова у всех.

Таблица: 26 латинских букв, 33 кириллические (включая `ё`), 10 цифр и пробел —
70 символов и 70 разных иероглифов. При запуске мод проверяет, что дублей нет и
все иероглифы лежат в диапазоне, который рисует шрифт Minecraft; если проверка не
проходит, мод падает на старте с понятным сообщением, а не портит чат молча.

Класс шифра вынесен за интерфейс `Cipher` (`encrypt` / `decrypt`), чтобы позже
можно было добавить другие режимы, не трогая остальной мод.

### Хендшейк

Пароль **никогда не передаётся по сети**. Вместо него в личку уходит токен
`vx-<nonce><flag><mac>`:

- `nonce` — два случайных иероглифа из таблицы;
- `flag` — один иероглиф: запрос или ответ;
- `mac` — шесть иероглифов, первые 36 бит `HMAC-SHA256(пароль, nonce + flag + текущая минута + ник отправителя)`, закодированные в системе счисления по основанию 70.

Как это выглядит:

1. Игрок A пишет `/vxchat B` → A отправляет B личку `/msg B vx-秋鸟请碘晨冰王九碘`.
2. У B мод перехватывает личку, прячет её из чата и считает MAC своим паролём.
   Расхождение по времени допускается ±1 минута.
3. Если пароли совпали: B добавляет A в синхронизированные, пишет в чат зелёное
   «Чат с A успешно синхронизирован» и автоматически отвечает таким же токеном,
   но с флагом «ответ».
4. A получает ответ, проверяет MAC — и тоже видит зелёное подтверждение. С этого
   момента оба видят расшифрованный текст.

Защита от зацикливания: на токен с флагом «ответ» автоответ не отправляется, и
одному игроку автоответ уходит не чаще раза в 10 секунд. При несовпадении пароля не
выводится ничего и ответа нет. Повторный токен от уже синхронизированного игрока
только обновляет синхронизацию, без лишних сообщений.

### Когда шифруется

Сообщения шифруются, если шифрование включено (`/vxon`) и выполняется хотя бы одно:

- на сервере есть синхронизированный игрок, который сейчас онлайн;
- включён переключатель «шифровать всегда».

Сообщения, начинающиеся с `/`, не шифруются никогда.

Лимит чата — 256 символов. Если после шифрования сообщение длиннее, поведение
задаётся переключателем в GUI: обрезать или не отправлять с предупреждением.

### Конфиг

`config/vxchat.json`, сохраняется при каждом изменении. Синхронизированные игроки
хранятся в разрезе серверов по адресу. `/vxreload` перечитывает файл на лету:

- если файла нет — создаётся с настройками по умолчанию;
- если JSON битый — настройки в памяти сохраняются, в чат выводится ошибка, а
  сломанный файл откладывается в `vxchat.json.bak`;
- если всё прочиталось — выводится «Конфиг перезагружен» с текущим состоянием.

Ключ никогда не выводится в чат и не пишется в логи.

## Ограничения

- **Шифр простой и статичный.** Это маскировка, а не защита. Подстановка «один символ → один иероглиф» ломается частотным анализом за минуты: частотный профиль латинского текста отличается от китайского, а сопоставление по длинам слов выдаёт язык. Цель мода — чтобы обычный игрок не прочитал сообщение, а не чтобы выдержал криптоанализ.
- **Таблица публичная.** Она одинакова у всех и лежит в коде мода. Пароль на неё не влияет.
- **На сервере с логами лички токены видны админам.** Токен — это HMAC от пароля, а не сам пароль: восстановить ключ из него нельзя. Но факт синхронизации и ники участников админ увидит.
- **MAC опирается на 36 бит** — этого достаточно, чтобы отсечь случайного наблюдателя, но не является полноценной криптографической защитой.
- **Синхронизация привязана к серверу.** Игрок должен быть онлайн на том же сервере. После перезахода ник остаётся в списке, но неактивен, пока не зайдёт.
- **Окно проверки времени — ±1 минута.** У клиентов с сильно рассинхронизированными часами хендшейк не пройдёт.
- **Текст всегда в нижнем регистре.** Регистр теряется, чтобы таблица не разрослась вдвое.
- **Знаки препинания не шифруются.** По ТЗ они остаются как есть — это видно наблюдателю.
